项目简介

「算法歧视众包观测」是一个公益性质的开源研究项目。它通过浏览器插件，在用户正常浏览电商商品页时 众包采集公开价格数据，再用统计方法检验：同一商品、同一时刻，不同用户看到的价格是否存在系统性差异。 如果发现稳定、可复现的价差模式，这些结果可作为公益诉讼与监管研究的证据线索，帮助回答 「大数据杀熟是否真的存在、有多普遍」这个公共问题。

我们采集什么

插件只在商品页触发，采集内容分为三类：

类别字段说明
商品价格展示价 / 到手价 / 优惠信息页面上公开展示的价格与促销文案，是比对分析的核心数据。
商品信息商品 ID / 名称 / 链接 / 平台用于把不同用户对「同一件商品」的报价归拢到一起。
浏览环境IP 城市、设备内存 / 核数 / 屏幕分辨率、User-Agent、是否登录、会员等级、是否新用户、注册天数、是否高峰时段描述「看到价格的是什么样的用户/设备」，用于分组检验价格差异是否与用户画像相关。全部为浏览器公开可读的属性。
🚫 明确不采集：账号密码、支付信息、聊天记录、浏览历史、通讯录等任何与价格无关的私密内容。 所有字段均为页面公开展示信息或浏览器环境公开属性。

隐私与匿名机制

  • 匿名身份：每位参与者由一串随机生成的 UUID 标识，仅保存在你自己的浏览器里，不包含姓名、手机号等任何个人信息，也无需注册。
  • 二次假名化：服务器在拉取数据做比对分析时，用户标识会被再次假名化为 u_ + SHA-256 前 10 位 的形式，分析侧看不到原始 UUID。
  • 文本脱敏：店铺名、用户标记等文本字段支持脱敏处理（保留首字，其余以 * 替代）。
  • 退出与删除：你可以随时在「我的看板」退出身份、清除本机标识；管理员也可以在后台删除数据。卸载插件即停止采集。

统计方法

  • 价格基准口径：优先取展示价作为比价基准；展示价缺失时回退到到手价，保证口径一致可比。
  • 分组比较：按匿名用户分组，比较同一商品在不同用户处的报价分布，而不是跨商品比价格高低。
  • 疑似阈值：组间价差达到或超过 5% 时，触发「疑似差异化定价」标记，进入进一步检验。
  • 显著性检验：使用 Mann-Whitney U 检验（对分布形态不做假设）与 Welch t 检验（允许两组方差不等）判断价差是否具有统计显著性。
  • 小样本降级：当某组样本量 < 3 时，不做显著性推断，只输出描述性统计（均值、极差等），并在结果中明确标注样本不足。
  • 跨商品复现：单个商品的价差可能来自促销时点等偶然因素；只有当同一平台的价差模式在 ≥ 2 个商品上复现时，才升级为「平台级疑似」。
⚖️ 重要提示：「统计疑似」≠「法律认定」。统计结果只能说明价格分布存在值得关注的差异模式， 是证据线索而非结论；是否构成法律意义上的价格歧视，需要由监管机关或司法机关结合更多事实认定。

数据通路

  • 上报：浏览器插件在商品页采集数据后，自动上报到服务器的 Postgres 数据库。
  • 分析：做比对分析时，可按商品从数据池拉取全池匿名数据到本地进行比对；分析副本可选择留存，也可在分析完成后立即删除。
  • 管理：管理员负责数据管理与演示数据清理，普通用户无法看到他人的原始身份标识。
