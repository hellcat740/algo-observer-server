安装步骤

  1. 下载 zip 后，解压到一个固定文件夹（例如 D:\algo-observer-plugin，之后不要移动或删除）。
  2. 打开 Edge，地址栏输入 edge://extensions 回车。
  3. 打开左下角 「开发人员模式」 开关。
  4. 点击新出现的 「加载解压缩的扩展」 按钮，选中刚才解压的文件夹。
  5. 安装完成。打开任意 淘宝 / 天猫 / 京东 / 拼多多 商品页，点击右上角插件图标即可开始采集。
  1. 下载 zip 后，解压到一个固定文件夹（之后不要移动或删除）。
  2. 打开 Chrome，地址栏输入 chrome://extensions 回车。
  3. 打开右上角 「开发者模式」 开关。
  4. 点击 「加载已解压的扩展程序」，选中刚才解压的文件夹。
  5. 安装完成。打开任意 淘宝 / 天猫 / 京东 / 拼多多 商品页，点击右上角插件图标即可开始采集。
ℹ️ 首次采集前请在插件弹窗中阅读并同意《采集知情同意》；插件默认上报到本项目公网服务器， 服务器地址与上报密钥已内置，无需任何配置。你也可以随时在插件「设置」页查看或修改上报地址。

常见问题

Q：提示「无法加载扩展」？
A：确认选中的是解压后的文件夹（里面直接包含 manifest.json），而不是 zip 或外层目录。

Q：装好后怎么知道自己的数据有没有上报成功？
A：点击插件图标查看最近采集结果；或在门户首页进入「我的看板」查看记录与统计。

Q：会收集我的个人信息吗？
A：不会。仅采集页面公开价格与优惠信息，昵称打码后才入库，身份为随机匿名编号。
