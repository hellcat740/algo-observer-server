# 固定参考网格与分类标签恢复设计

日期：2026-10-31  
状态：方案一已确认  
分支：`feat/unified-balance-ui`

## 1. 目标与范围

调整 `/space` 的三维参考网格和分类文字：

- 天上、地下及侧向参考网格固定在世界坐标中，不再随相机、OrbitControls 目标点或 WASD 平移。
- 恢复大类、小类名称，标签锚定在对应分类圆柱内部的时间原点附近。
- 保留现有筛选、点选、2D／3D、时间播放、无限分类圆柱、对比椭球与连线、双用户比较和数据接口。

不引入新的依赖、外部字体、HTML 标签层或屏幕固定网格。

## 2. 固定世界网格

`space.js` 已创建 XY、XZ、YZ 三个 2000×2000 的着色器网格平面。当前 `updateGrids()` 每帧把平面位置吸附到 `controls.target`，导致导航时参考网格一起移动。

实施时删除这段位置更新，三个平面保持创建时的世界原点位置和原有旋转。`updateGrids()` 只负责：

- 3D 显示三个平面，2D 只显示 XY 平面；
- 根据相机到目标点的距离调整十进制网格步长；
- 保留原有着色器的固定 UV 网格线和远处淡出。

网格仍在旋转视角时呈现正常透视变化，但其世界位置不随旋转、缩放、WASD 或右键平移改变。有限几何范围和现有导航无硬边界的行为均不在本轮扩展。

## 3. 分类圆柱内标签

恢复本地 Canvas 生成文字纹理的 `categoryLabel(category)`，使用 Three.js Sprite，不请求外部资源。

- 每个当前可见的大类、小类在创建圆柱时同时创建一个标签。
- 标签文字分别使用 `category.l1` 和 `category.l2`，不显示完整层级路径。
- 标签位于 `category.center` 的 XY 坐标和 `z=0.25`，处于对应无限圆柱内部，不随 `controls.target.z` 移动。
- 大类使用较大、较亮文字，小类使用较小、较低对比文字；标签朝向相机，无深度写入。
- 每帧按相机距离限制屏幕尺寸，避免远处过大或近处失控。
- 大类标签优先保留；小类仅在足够近或属于当前选中商品时显示，降低密集区域遮挡。
- 标签只在 3D 显示，并受现有“分类圆柱”图层开关统一控制。

`updateCategoryVisuals()` 按 `object.userData.type` 分别处理：只让无限圆柱的 Z 中心跟随当前目标，标签保持固定时间原点位置。分类显隐集合和布局计算不变。

## 4. 数据流与资源管理

完整数据载入仍由 `buildSemanticLayout()` 生成固定分类锚点和圆柱描述。筛选只决定哪些分类及标签可见，不改变锚点、网格世界坐标或标签文本。

清空分类 Group 时继续调用现有 `disposeObject()`，释放标签 CanvasTexture 和 SpriteMaterial，避免刷新或筛选时累积 GPU 资源。Canvas 2D 上下文不可用时不执行本轮以外的复杂回退；现有浏览器运行环境与原标签实现一致。
