# 管理员观测分类与编辑设计

日期：2026-10-30

## 目标

精简管理员控制台导航，在观测数据列表中直接展示商品分类、手动启动后台分类，并允许管理员在删除按钮前进入单条记录编辑。保留现有三维空间与高维可视化页面及其深链，只移除控制台“高维可视化”标签。

## 控制台与分类

删除 `api/app/static/index.html` 侧边栏的“高维可视化”入口，不删除 `/visualization` 路由、静态页面或 `/space` 功能。

观测表格增加“类别”列，按 `category_l1 / category_l2` 展示；有三级分类时在详情中保留完整分类。无分类缓存显示“未分类”。分类通过独立的管理员只读接口按当前页观测批量获取，不在观测列表请求或分类查询中调用模型，不改变原始观测响应结构，避免影响其他调用方。

观测数据顶部增加“分类”按钮，HTML `title` 和可访问说明均为“后台分类未分类商品”。按钮调用现有 `POST /api/space/classification-check`，每轮最多处理 100 个未缓存商品；随后轮询现有状态接口，显示运行、完成、未配置或失败状态，运行中禁用按钮避免重复操作。完成后重新加载当前页分类与观测列表。

## 单条编辑

每行操作顺序为“详情 / 编辑 / 删除”，编辑按钮位于删除按钮前。点击编辑复用现有详情抽屉，以表单展示所有业务字段：商品与平台、价格与促销、用户上下文、设备环境、采集时间与证据信息。

观测 ID、入库时间和同步元数据（来源、同步时间）只读，防止破坏主键与同步链路。其他现有业务字段可编辑，包括匿名用户引用；若匿名用户引用改变，服务端同步调整新旧用户的观测计数，避免汇总失真。

固定格式字段使用选择控件：

- `is_login`、`is_new_user`、`peak_hour`：是／否／未知，未知保存为 `null`；
- `currency`：系统当前支持的 CNY、USD；
- `platform_code`：系统支持的平台编码；
- 其他自由文本、数值和日期字段使用匹配的文本、数字、复选或日期时间控件，不用自由文本模拟布尔值。

## 更新接口与数据一致性

新增管理员鉴权的 `PUT /api/observations/{observation_id}`。请求使用完整业务字段结构，服务端复用现有清洗与业务校验，成功后返回更新后的完整观测。接口不允许通过请求体修改观测 ID、入库时间或同步元数据。

商品名称、平台、商品 ID、卖家或链接改变后，现有分类缓存键自然改变，该记录显示“未分类”，等待后续分类；旧缓存保留供未修改的同商品观测使用，不做全局删除。编辑其他字段不影响分类。

更新匿名用户引用时，在同事务中调整旧、新 `users` 记录：旧用户计数减一且不低于零；新用户不存在则建档，存在则增加计数并更新活跃时间。记录不存在返回 404，字段校验失败返回 422，未授权返回 401。前端保存失败保留表单内容和错误提示，成功则关闭编辑状态并刷新当前页。

## 测试与验收

- 控制台无“高维可视化”标签，原路由仍可访问。
- 当前页类别正确映射，未缓存显示“未分类”，列表加载不调用模型。
- “分类”按钮文字、悬停说明、管理员鉴权、运行中禁用与完成后刷新。
- 编辑按钮位于删除前；固定格式字段使用下拉选择，未知布尔值正确保存为 `null`。
- 更新接口管理员鉴权、清洗校验、完整字段更新、不可变字段保护、404/422。
- 商品字段修改后显示未分类，非商品字段修改后分类保持不变。
- 匿名用户变更的计数调整与数据库事务。
- JavaScript 语法、全部 Python 回归和敏感信息扫描通过；每次改动提交 Git。
