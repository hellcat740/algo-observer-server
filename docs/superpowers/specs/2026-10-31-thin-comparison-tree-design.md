# 三维观测空间：仅保留细最小树

## 目标

从三维观测空间移除全部时间簇椭球，只显示每个可分析商品组的一棵细最小生成树。自动用户对、红／黄／绿疑似程度、商品筛选和 2D／3D 行为保持不变。

## 方案比较

1. **仅移除前端椭球渲染（采用）**：删除 `space.js` 的椭球创建、缩放和计数，直接用分析点位置框定相机。改动最小，不影响已经验证的几何算法。
2. 同时删除几何模块的时间簇计算：可减少少量计算，但会扩大接口和回归测试范围，对当前视觉需求没有必要。
3. 重新设计点布局以突出树：可能改变分类语义坐标，超出本次需求。

## 实现

- `renderComparison()` 不再创建 `THREE.SphereGeometry`、`comparison-ellipsoid` 或读取 `descriptor.clusters`。
- 每组仍只渲染 `descriptor.treeLines`，全部连线沿用 `comparePriceGroups` 的红／黄／绿结论。
- 相机改为根据所有可分析组的实际点坐标自动框定，不依赖已删除的椭球。
- `updateComparisonVisuals()` 只更新树连线；半径改为 `Math.max(0.35, distance * 0.0015)`，使细线在远处仍可辨认。
- 右侧卡片只报告最小树边数，不再报告时间簇椭球数量。

## 验证

- 静态测试先断言椭球相关标记不存在，并确认细线厚度、树渲染和点坐标取景存在。
- 运行全部 JavaScript 和 Python 测试。
- 浏览器确认只有数据点和细树，没有球簇；商品隔离、图层开关及 2D／3D 切换保持可用。
