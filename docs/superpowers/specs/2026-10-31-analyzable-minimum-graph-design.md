# 三维观测空间：自动商品配对与整组最小子图

## 目标

在当前筛选出的观测点中，按项目歧视分析的“同商品、不同匿名用户、中位价价差最大用户对”规则自动选取可分析数据，为每个商品组只生成一个最小生成树，并沿用现有红、黄、绿疑似程度规则着色。

## 方案比较

1. **前端自动分组 + 整组最小生成树（采用）**：直接复用当前筛选点、三维坐标和共享价格判定；2D／3D 行为一致，不需要扩展 API。
2. 后端预计算配对和边：便于其他页面复用，但三维坐标只存在于前端，仍需传输并二次计算几何，改动范围更大。
3. 保留手选用户和簇内最小树：实现最小，但不符合自动配对及“每组仅一个最小子图”的要求。

## 数据选择与分组

- 仅使用当前筛选结果中具有有限、非负 `normalized_price_cents` 的观测点。
- 按 `product_key` 分组，再按 `user_pseudonym` 聚合价格并计算中位数。
- 每个商品选取中位价最低和最高的两个不同用户；中位价并列时，观测数较多者优先，再按用户假名稳定排序。这与歧视分析的最大价差用户对规则一致。
- 少于两位有效用户的商品不生成分析连线；缺价点不参与配对、判定或连线。
- 选中一个商品时只显示该商品的比较图层；未选中时显示当前筛选结果中的所有可分析商品组。

## 最小子图与颜色

- 对每个商品自动选出的两位用户的全部有效点计算**一个跨完整时间范围的最小生成树**，不再按时间簇分别生成多棵树，也不再添加簇中心之间的额外连线。
- 使用三维欧氏距离和确定性 Prim 算法；2D 使用同一算法，仅将 Z 坐标压为 0。
- 一个含 `N` 个非重合有效点的组生成 `N−1` 条边，连通且无环；单点不生成边。无效坐标和零长度边不渲染。
- 保留现有 24 小时时间簇椭球作为辅助显示，但椭球不参与图连接。
- 每组的全部连线共享 `comparePriceGroups` 对该组完整价格序列的结论：红色为严重疑似，黄色为关注／低置信，绿色为未见明显差异，不新增第二套颜色阈值。

## 界面与异常状态

- 将“同商品双用户价格序列”的手选用户控件改为自动配对结果说明，展示商品、用户对、颜色结论和最小树边数。
- 用户图例加粗自动配对涉及的用户；比较图层开关同时控制最小树与时间簇椭球。
- 没有可分析组时显示明确空状态；筛选、选择商品、切换 2D／3D 或载入新数据后重新计算。
- 算法不修改输入点；相同输入与坐标生成稳定顺序的边。

## 测试与验收

- 单元测试覆盖最大中位价差用户对、并列稳定性、无效价格、单用户商品、多商品分组和输入不变性。
- 几何测试覆盖整组 `N−1` 条边、连通无环、跨时间簇连接、2D、无效坐标、重合点及稳定顺序。
- 静态回归测试确认不再渲染簇中心连线，页面不再要求手选用户，仍复用共享颜色规则。
- 运行全部 JavaScript 与 Python 测试，并在浏览器验证演示数据的红、黄、绿连线、商品选择联动、图层开关和 2D／3D 切换。
