# 我的看板：本机商品比对与观测详情设计

日期：2026-10-28

## 目标

1. “比对分析”只搜索和自动分析当前匿名身份已经采集过的商品，不再展示全池无关商品。
2. 每项比对仍使用该商品在远端数据池中的全部匿名观测，以便进行用户间比较。
3. “我的观测记录”支持点击行展开或收起完整详情。
4. 插件每次内容迭代必须同步提升版本号并重新打包，避免用户无法区分已安装版本。

## 数据范围与接口

### 本机商品范围

在 `pool_api.py` 增加当前用户商品列表接口，使用现有 `X-User-Id` 鉴权与 `user_ref` 数据归属：

- 只查询 `Observation.user_ref == 当前匿名身份` 的记录。
- 按 `platform_code + product_id` 联合去重，防止不同平台相同商品 ID 被误合并。
- 返回商品名称、平台、商品 ID、本机观测数、最近采集时间。
- 支持可选关键词与平台过滤，供手动搜索复用。
- 不按全池观测数过滤；本机只有一条记录的商品也可进入候选，其远端数据可能不足，分析结果继续沿用现有“仅 1 个用户”提示。

### 远端比对数据

现有 `/api/pool/observations` 增加可选 `platform_code` 过滤。`lab.html` 拉取比对数据时同时传 `platform_code` 和 `product_id`，确保只取得同一平台同一商品的远端记录。

不改变远端池数据的匿名化字段、返回上限和分析算法。

## 比对分析交互

- 手动搜索改为调用本机商品接口，关键词和平台筛选均只作用于本机商品。
- 自动模式改为获取本机商品列表，最多依次分析前 10 项。
- 无本机商品时提示先使用插件采集；筛选无结果时提示没有匹配的本机商品。
- 远端观测不足时保留现有无有效价格、单用户等状态，不报错。
- 请求失败保留现有错误提示，不清空已经生成的分析结果。

## 我的观测详情

- 每条摘要记录可点击，也可通过键盘聚焦后按 Enter 或空格操作。
- 点击后在当前行下方插入详情行，再次点击收起；每条记录独立维护展开状态。
- 详情直接使用当前分页接口已经返回的字段，不新增详情请求。
- 展示：观测 ID、平台、商品 ID、完整商品名、商品链接、卖家 ID、展示价、到手价、优惠金额、促销类型及说明、币种、登录状态、会员等级、新用户状态、注册天数、IP 城市、配送城市、库存提示、设备平台、语言、内存、CPU 线程数、屏幕分辨率、设备价格评分、高峰时段、采集时间、入库时间、来源及同步时间。
- 布尔值显示“是 / 否”，空值统一显示“—”；金额沿用币种符号。
- 商品链接仅允许 `http:` 和 `https:`，所有动态文本及链接属性统一转义。
- 切换分页后重新渲染记录，不保留其他页的临时展开状态。

## 插件版本规范

- 每次修改插件脚本、权限、页面或资源时，同时提升 `manifest.json` 的 `version` 并重新生成 `plugin.zip`。
- 新增平台或用户可见能力使用次版本号，缺陷修复使用补丁号；不修改插件内容的纯服务端或看板改动不产生无意义的插件版本。
- 打包测试不再永久断言 `1.0.0`，而是校验合法语义化版本，并在发生插件迭代时同步更新预期版本。

## 测试

- 服务端：本机商品只包含当前用户数据；联合平台与商品 ID 去重；关键词和平台筛选；远端观测联合过滤；其他用户不能读取本机商品范围。
- 前端结构或脚本：搜索与自动模式使用本机商品接口；分析请求同时携带平台和商品 ID；空状态文案正确。
- 详情：行可展开与收起；详情字段完整；空值、布尔值和美元金额格式正确；动态内容转义。
- 回归：现有身份同步、插件采集、Amazon 入库、数据同步和路由测试全部通过。

## 非目标

- 不修改统计检验算法、阈值和匿名化口径。
- 不允许搜索或分析用户从未采集过的商品。
- 不新增观测详情编辑或删除功能。
