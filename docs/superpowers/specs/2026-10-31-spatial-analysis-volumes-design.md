# 空间分析包围体与图层交互设计

日期：2026-10-31
状态：已对齐，待实施

## 目标

在不改变现有数据、双用户同商品对比和严重程度判定规则的前提下，重构三维观测空间的分类与对比几何，补齐当前未实际呈现的包围球和时间簇连线，并统一 2D／3D 的键盘平移体验。

## 范围

- 删除截图所示“关系图层”整组旧复选框：同商品、同用户、同用户同商品、时间邻近、疑似价差、促销差异、当前对比。
- 保留后台关系数据、统计结果和现有 API，不删除后台关系计算。
- 新面板只提供“分类圆柱”和“对比分析”两个显示开关，默认均开启。
- 不修改商品价格、采集用户、分类缓存和共享对比判定规则。

## 分类圆柱

- 大类和小类圆柱的中心与 XY 半径沿用现有语义布局，继续按相机距离调节透明度。
- 圆柱沿 Z 时间轴在视觉上无限延伸：使用足够长的开放圆柱几何，并随观察目标沿 Z 轴重新居中，避免在正常导航中看到端面或尽头。
- 不再创建类别文字 Sprite，也不显示圆柱端面。
- “分类圆柱”关闭时，大小类圆柱整体隐藏，数据点、对比几何和交互保持不变。

## 对比分析几何

- 仅使用当前有效对比的人民币折算价数据点，继续要求两个不同用户和同一商品。
- 将双方有效点合并后按 `fetch_ts` 升序排列；相邻点时间差不超过 24 小时时归入同一时间簇，超过 24 小时开始新簇。无效时间不参与几何，但不改变统计样本。
- 每个时间簇创建一个最小轴对齐包围椭球：中心为各轴最小值与最大值的中点，半径为各轴范围的一半；退化轴使用小而有限的显示半径，确保单点和平面点仍可见。该定义是可测试的最小轴对齐包围椭球，不宣称是任意旋转下的全局最小体积椭球。
- 椭球使用透明表面，不遮挡数据点；颜色使用当前共享对比结论：红为严重疑似，黄为关注／低置信，绿为未见明显差异。
- 相邻时间簇之间只画一条中心到中心的线，替代当前全量笛卡尔积连线和包围圆。线同样使用共享结论颜色，清楚呈现相距较远的数据对象。
- “对比分析”关闭时，椭球与时间簇连线整体隐藏，文字统计、双用户价格序列和其他视图保持可用。
- 2D 中所有点仍压到 Z=0，包围体随数据变为扁平椭球，时间簇关系仍由同一数据描述驱动。

## 2D 键盘平移

- 3D 保留现有 WASD 行为。
- 2D 启用同一套 `movementVector` 与按键状态处理，在 XY 分类平面移动相机和观察目标。
- 2D 平移不改变点的 Z 压缩，不启用旋转，不干扰输入框、选择框和表格操作。
- 更新操作提示，明确 2D／3D 均支持 WASD。

## 代码边界

- `space-volumes.js`：提供时间簇划分、最小轴对齐包围椭球描述和簇间连线描述，纯函数可独立测试。
- `space-layout.js`：分类描述不再依赖有限时间高度。
- `space.js`：创建无限视觉圆柱、透明椭球和少量簇间线，统一两个图层开关，并扩展 2D 键盘移动。
- `space.html`：替换旧关系选项与操作提示。

## 验证

- 单元测试覆盖 24 小时边界、无效时间、单点与退化椭球、所有点被包含、簇间仅一条线，以及共享红黄绿颜色输入。
- 测试分类开关和对比开关只控制各自 Group，2D WASD 同时移动相机和目标且不改变 Z。
- 运行全部 Python 测试模块和全部 JavaScript 测试。
- 浏览器使用真实数据验证：旧选项消失、两个新开关有效、椭球和线实际可见且颜色与文字结论一致、圆柱看不到尽头、2D WASD 平滑移动。
