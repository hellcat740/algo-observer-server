# 管理员三维观测空间设计

日期：2026-10-29

## 目标

在管理员控制台增加“三维数据空间”入口，提供 `/space` 页面，按附件实现 Three.js 三维交互、二维与表格视图、可解释关系线、统计状态、筛选、时间播放、双用户对比、CSV 导出和明确的演示数据模式。

页面始终提示：“统计疑似不等于法律认定，可视化结果仅用于研究线索筛查。”

## 架构

新增独立的 `space_api.py`、数据计算模块 `space.py` 和静态 `space.html`/`space.js`。复用现有观测点构造、商品稳定键、汇率缓存和分类缓存，不修改 Observation 字段或原始数据。

Three.js 与 OrbitControls 使用固定版本并保存在 `api/app/static/vendor/`，通过 FastAPI 静态目录提供，运行时不访问 CDN。数据点使用 `THREE.Points + BufferGeometry`，关系线使用 `THREE.LineSegments`，拾取使用 `THREE.Raycaster`，旋转、缩放和平移由 OrbitControls 提供。

## 非阻塞分类

`/api/space/points` 只读取已有分类缓存，不在请求线程调用大模型。缺少缓存的点返回空分类字段，页面显示“未分类/待分类”，原始观测仍立即可见。

请求通过 FastAPI BackgroundTasks 启动唯一的后台分类任务；任务去重后分批处理，每批最多 50 个商品，单次模型请求仍可只处理一个商品。提供 `/api/space/classification-status` 返回 `idle/running/success/error/not_configured`、待处理数、完成数、失败数和时间。前端轮询状态，完成后手动或自动刷新点数据。

任务状态是进程内运行状态，不作为新的业务数据表；分类结果仍持久化在现有 `product_category_cache`。模型失败不修改原商品，不伪造分类。

## 数据接口与性能

`GET /api/space/points` 复用管理员 `X-API-Key` 鉴权，页面不新增密钥输入框，只读取控制台已经保存的登录状态。直接访问页面且无登录状态时，只能主动进入明确标注的 mock 演示模式。

响应包含：

- `points`：现有完整观测点字段，另加优惠金额、商品样本量、商品价格偏差、价差方向和统计状态；
- `edges`：`type/source/target`；
- `statistics`：同商品不同用户组的描述性统计、样本量、Mann-Whitney U 与 Welch t 结果；
- `meta`：数据库总数、返回数、是否抽样、关系是否截断、分类任务状态及平台级复现状态。

单请求最多返回最近 20,000 条；数据库更多时明确标记抽样。少于 5,000 条全量渲染，5,000 至 20,000 条限制关系线并自适应点大小。关系候选超过 1,000 条时只返回前 1,000 条并提示缩小范围。

## 坐标模式

### 业务坐标

- X：`fetch_ts` 的标准化时间；
- Y：一级分类层级，缺失归入“未分类”；
- Z：同 `product_key` 内 `normalized_price_cents` 相对中位数的偏差；空折算价不参与中位数和价差，点放在零层并使用特殊边框。

金额在数据库和接口中始终保持整数分，只有显示为元时除以 100。价格基准仍为展示价优先、到手价回退，CNY 与 USD→CNY 规则及汇率回退标记不变。

### 高维嵌入

把时间、小时、高峰、分类、用户假名、平台、城市、设备评分、登录、会员、新用户、价格、优惠和促销编码为特征，通过确定性特征哈希投影到三维。界面明确标注该模式为“高维特征投影”，并保留 PCA/t-SNE/UMAP 替换接口，不冒充已运行这些算法。

## 关系与统计

所有关系由服务端字段计算：

- `SAME_PRODUCT`：平台与商品 ID 相同；
- `SAME_USER`：非空稳定假名相同；
- `SAME_USER_PRODUCT`：稳定假名与 `product_key` 均相同；
- `TIME_NEIGHBOR`：同商品且时间差不超过可配置的 24 小时默认阈值；
- `PRICE_GAP`：同商品、不同用户、折算价非空，两组中位数差异 `abs(a-b)/max(a,b) >= 5%`；
- `PROMO_DIFFERENCE`：同商品但促销类型、说明或优惠金额不同。

每类关系有固定颜色和独立开关。无折算价和不支持币种不得生成 `PRICE_GAP`。

按商品和用户聚合计数、价格中位数及偏差。任一组样本量小于 3 时只返回描述性状态，不返回显著性标签；两组均达到 3 时计算 Mann-Whitney U 和 Welch t。价差达到 5% 只标为“疑似差异”。同一平台至少两个商品复现时才标记“平台级疑似”，并同时显示样本量和统计状态。

## 页面交互

- 默认业务坐标 3D；窄屏默认 2D。
- 左键旋转、滚轮缩放、右键平移；悬停显示完整详情；点击突出同商品点。
- 3D、2D、表格切换；业务坐标与高维特征投影切换。
- 点颜色支持平台、一级分类、用户聚类、价差方向、新用户、登录、高峰；点大小表示商品样本量；透明度表示分类置信度；空折算价用特殊边框。
- 支持时间段、时间滑块和播放，平台、分类、用户、城市、促销、价差筛选及商品名搜索。
- 支持选择两个匿名用户，展示其同商品时间—价格序列。
- 支持导出当前筛选点 CSV；导出只含界面允许的假名字段，不含原始 UUID 或 User-Agent。
- 本地 mock 仅在无真实数据时由用户主动开启，并持续显示“演示数据”标记。

## 控制台与静态资源

控制台侧边栏增加 `/space`“三维数据空间”入口。新增 `/space` 页面路由和 `/static` 静态资源挂载。Three.js 固定为 0.170.0，OrbitControls 使用同版本；保留来源和版本说明，不运行时下载。

## 测试

- 点口径、UTC、匿名和币种继续由原测试保证。
- 新测试覆盖六类关系、24 小时阈值、5% 中位数价差、空折算价/不支持币种排除、1,000 条上限。
- 小样本降级、达到样本量后的 MWU/Welch 字段、平台级复现。
- 缓存缺失立即返回“未分类”，请求不同步调用模型，后台任务状态与鉴权。
- `/space` 路由、控制台入口、本地 Three.js 资源、无 CDN、无密钥输入、无原始 UUID。
- JavaScript 语法、mock 标识、CSV 字段和窄屏默认 2D。
- 全量回归测试通过后提交并合并本地主分支；插件内容不变，版本保持 1.1.0。
