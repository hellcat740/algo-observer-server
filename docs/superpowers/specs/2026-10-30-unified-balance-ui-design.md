# 算法衡器馆：全站统一 3D 视觉改版设计

日期：2026-10-30  
状态：已确认概念方向（方案一）  
分支：`feat/unified-balance-ui`

## 1. 目标与边界

将算法歧视众包观测网站的门户、用户侧页面、管理侧页面、可视化与下载页统一为“算法衡器馆”视觉体系：当代编辑式排版、古典精密仪器、暖纸色空间与柿橙／密金撞色。

本次只改变视觉表现、页面布局、共享样式和首页／三维场景的渲染交互。以下行为保持不变：

- 所有现有路由、深链和导航目标；
- 匿名 UUID 的生成、导入、退出与插件身份对齐；
- 用户侧标签切换、同源 iframe 懒加载和分页；
- 商品搜索、数据拉取、本地分析、留存与清空；
- 管理员登录、本地密钥保存、控制台各视图与数据管理；
- 二维／三维／表格切换、筛选、搜索、点选、关系图层、时间播放、双用户比较和 CSV 导出；
- 现有 API 请求、字段口径、统计规则、研究边界与错误语义。

不引入 React、Vue 等框架，不改变 FastAPI 路由与后端数据结构，不接入 CDN，不生成或下载外部 3D 模型。

## 2. 视觉概念

### 2.1 设计关键词

**衡平、证据、匿名、观测、克制。**

首页天平是“利益与算法是否平衡”的核心隐喻；其余页面是围绕证据展开的工作台。3D 只服务于主题叙事和真实数据分析，不用无意义粒子、星空、霓虹或持续漂浮卡片装饰页面。

### 2.2 色彩

核心色取自参考图：

- 柿橙 `#B85516`：主操作、当前导航、重点链接、关键状态；
- 密金 `#EAAE35`：天平金属、重点数据、价差关系与视觉高光；
- 暖象牙白：页面底色和阅读区域；
- 深墨棕：正文、导航和仪器舱背景；
- 浅沙色与细棕线：卡片、分隔线和输入边界。

价格方向、平台、分类和关系类型仍需可区分的辅助色。辅助色采用低饱和青绿、灰蓝、紫灰等，并配合文字、形状或线型，不能仅依赖颜色传达结论。所有正文和交互状态满足可读性对比要求。

### 2.3 字体与材质

使用系统中文无衬线字体保证正文、数字和表格效率；首页大标题可使用系统宋体／衬线字体形成编辑式对比，不加载外部字体。材质语言为暖纸、磨砂金属、细刻度与轻微暗影，不使用大面积玻璃拟态和强烈泛光。

## 3. 首页 3D 天平

### 3.1 构图

桌面端采用非对称双栏：左侧为项目标题、说明及三个现有入口，右侧为 3D 天平。移动端按标题、天平、入口重排，入口保留原有顺序和链接。

天平参考古典立柱、弧形横梁、吊链与浅托盘轮廓，简化雕刻。左盘承载金币、价格标签与折扣几何符号，代表利益；右盘承载芯片、节点连接与代码括号，代表算法。两侧物体视觉重量接近，不把“算法”天然表现为负面。

### 3.2 场景与运动

使用本地 Three.js 和程序化几何体构建，按底座、立柱、横梁枢轴、左右悬挂组件和承载物分组。

- 鼠标横向位置映射横梁目标倾角，限制在约 ±6°；
- 鼠标纵向位置仅影响极小的观察视角，不增加额外倾斜；
- 使用帧时间归一化的阻尼插值平滑跟随；
- 托盘近似保持水平，吊链与横梁端点联动；
- 静止时有极轻微金属高光变化，不自动大幅摆动；
- 鼠标离开、窗口失焦或页面隐藏时回正并停止不必要渲染；
- `prefers-reduced-motion` 下取消跟随与呼吸动效，显示稳定构图；
- WebGL 创建失败时显示本地静态天平回退图，标题和入口仍完整可用；
- 移动端使用稳定的轻微自动运动或静态构图，不依赖悬停。

Canvas 不拦截标题、按钮、导航和文本选择。场景按容器尺寸与设备像素比调整，并限制像素比避免高分屏过度开销。

## 4. 全站页面体系

### 4.1 共享基础

提取共享设计令牌和基础组件样式，覆盖颜色、字体、间距、圆角、阴影、按钮、输入、卡片、徽章、提示、表格、侧栏与焦点状态。共享层只定义表现，不接管各页面状态。

页面已有功能脚本原则上保持原结构。若必须调整 DOM，保留所有既有 ID、数据属性、表单字段和事件绑定，避免破坏功能。

### 4.2 用户侧

门户、我的看板、数据池总览、比对分析、方法说明使用一致的暖白工作区、深墨棕导航和柿橙主操作。保留看板标签和 iframe 懒加载；嵌入页隐藏自身顶栏的现有机制不变。

统计卡片突出数字层级，趋势图和平台条形图采用共享色板。观测详情、分析结论、本地留存说明继续优先可读性，方法说明保持长文阅读宽度。

### 4.3 管理侧

管理员登录、控制台、旧版管理深链、统计分析使用同一组件语言。控制台保留侧边导航、hash 路由、密钥框、健康检查和各管理视图，不重写为新的应用结构。

危险操作仍以明确文字和警告样式区分，柿橙不能替代所有危险红色。加载、空数据、错误、成功和警告状态保持可识别。

### 4.4 二维与三维数据空间

保留现有专业数据工作流，统一为暖深棕“仪器舱”与浅色工具面板的组合。现有坐标、关系、筛选、时间播放、统计和表格逻辑不变，仅更新场景背景、网格、默认材质、控件和详情面板。

分类颜色通过固定映射和图例表达；疑似价差继续使用方向文本和统计状态，不因主题换色改变 HIGH／LOW 语义。研究边界提示保留在显眼位置。

### 4.5 下载与登录

插件下载页采用一致的编号步骤和明确的下载主按钮，不更改安装包地址。管理员登录保持原有密钥校验、本地存储与跳转行为。

## 5. 架构与数据流

- `api/app/static/` 继续承载全部静态页面；
- 新增共享 CSS，以及首页天平所需的独立 JavaScript 模块和静态回退资源；
- Three.js 继续引用 `/static/vendor/` 中固定版本文件；
- 首页天平不请求业务数据，不接触匿名 ID 或管理员密钥；
- 数据页仍使用原有 API 和鉴权头，3D 首页与数据空间互不共享运行时状态；
- 共享样式通过类名和自定义属性生效，不改变接口数据或脚本状态机。

## 6. 响应式、可访问性与性能

- 桌面、平板、窄屏逐级重排，保留现有移动端默认识别和 2D 回退；
- 所有按钮、输入、表格行与导航保留键盘操作和清晰焦点；
- Canvas 提供可理解的替代说明，装饰性元素不进入无障碍阅读顺序；
- 不依赖 hover 才能发现核心功能；
- 限制设备像素比，页面不可见时停止动画，卸载时释放几何体、材质和事件；
- 首页静态内容不等待 3D 初始化即可阅读和点击。

## 7. 错误处理

- WebGL 不可用或初始化异常：仅替换天平为静态回退，不影响导航；
- 数据请求、鉴权和分析错误：沿用原有提示与重试路径，只更新样式；
- 空数据、演示数据、截断、待分类和汇率警告：保留原文字与显示条件；
- 减少动态效果或低性能环境：回退为静态／低动画，不降低数据和功能完整性。

## 8. 验证与成功标准

### 自动化

保留并运行现有测试；为新增纯逻辑（如目标倾角计算、阻尼边界、回退条件或共享静态资源存在性）补充适当测试。运行页面／脚本语法检查及项目现有测试集。

### 本地人工验证

- 首页三个入口、键盘操作、鼠标跟随、回正、减少动态和 WebGL 回退；
- 匿名身份生成、导入、退出及四个用户侧标签；
- 数据池加载、商品搜索、分析、留存和删除；
- 管理员登录、控制台导航、健康状态和主要数据视图；
- 二维／三维／表格、筛选、点选、关系、时间播放、比较与导出；
- 下载链接、窄屏布局及主要浏览器控制台无新增错误。

完成标准：全站视觉统一且首页天平符合参考意象；所有原有功能和路由保持可用；测试通过；不以视觉改版名义修改统计口径或后端数据语义。
